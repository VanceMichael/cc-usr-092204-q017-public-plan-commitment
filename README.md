# 民生规划承诺兑现

本项目把五年民生规划的量化承诺、年度施政项目与公开进度证据连接在同一套语义下：
市民可从一个目标看到**最新结果、延期解释与下一节点**，监督人员可在任一时点
**重算为何被判定为按期、预警或偏离**。

## 领域事实

- 五年规划量化：公营房屋 **196,000** 个单位、劣质分间单位（劏房）治理、
  公立医院病床、地区康健中心受惠人数、青年实习与交流名额。
- 每个承诺拆解为累计里程碑，并关联预算、责任机构、空间项目、公众咨询意见与证据快照。
- 年度施政项目可调整**实现路径**；改写五年目标必须经正式修订程序，修订链保留原目标与桥接数字。
- 统计口径变化以桥接公式保留可比性：新口径值 = 旧口径值 × factor + constant。
- 跨部门数据超过报送滞后期时，进度标注「跨部门数据迟到，待报」，不以旧数冒充按期。
- 社区组织只能反馈获**逐案授权**的去标识个案；未公开选址地址与个人申请信息不得入库外泄。
- 编制过程收到超过一点七万份公众意见。

## 判定规则（对公众与监督完全一致）

1. 在里程碑累计曲线上按日期分段线性插值，得到「截至本日应完成量」。
2. 实测累计值按口径桥接折算为现行口径，缺口率 = (应完成 − 实完成) / 应完成。
3. 缺口率达 `warning_pct` 为**预警**，达 `breach_pct` 为**偏离**，否则**按期**；无数据为预警。
4. 置信状态：`verified`（已核实）／`provisional`（初步数字）／`overdue_pending`（数据迟到待报）。
5. 每次判定生成确定性 `basis_hash`（阈值、应完成、实完成、口径链、数据截止日），同一输入恒得同一结果。

截至样例基准日 2026-09-26 的态势：公屋预警（初步数字）、劏房治理按期、
康健中心按期、病床偏离（跨部门数据迟到）、青年项目预警（目标已经正式修订 60,000→54,000）。

## 目录说明

- `contracts/` 交换契约：`pledge`（承诺与里程碑）、`initiative`（年度项目）、
  `progress`（口径桥接与量度）、`governance`（选址、证据、咨询、授权反馈、修订）。
- `fixtures/` 去标识领域样例，含未公开选址、口径切换、路径重排与正式目标修订各一例。
- `src/assess.py` 纯函数：插值、桥接、置信派生、判定与 `basis_hash`。
- `src/catalog.py` 仓储：引用完整性与治理规则校验、授权校验、脱敏与公众／监督双视图。
- `src/server.py` HTTP 入口。
- `tests/` 31 项核对：判定阈值、口径桥接、迟到置信、修订链不可偷改、授权与脱敏、时间线重算。

## 服务入口

```bash
python3 -m src.server
```

- `GET /health`
- `GET /pledges?as_of=YYYY-MM-DD` — 全部承诺的状态板（默认今天）
- `GET /pledges/{id}?as_of=...` — 公众视图：最新结果、延期解释、下一节点、预算、年度项目、咨询意见、证据
- `GET /oversight/pledges/{id}?as_of=...` — 监督视图：判定依据与 basis_hash、修订链、授权个案、时间线重放
